System requirements / software dependencies
============================================

Operating system tested on:
  macOS Sequoia 15.7.7 (Darwin 24.6.0), Apple Silicon (arm64)

R version tested on:
  R version 4.5.0 (2025-04-11)
  Platform: aarch64-apple-darwin20

No non-standard hardware is required. All analyses were run on a standard
desktop/laptop or institutional compute cluster (CPU only; no GPU required
for the R-based analysis scripts in this repository).

Notes
-----
- Package versions above reflect the environment the scripts were verified
  to run in at the time of code cleaning; earlier/later minor versions of
  most CRAN/Bioconductor packages are expected to work but were not
  explicitly tested.
- GitHub-only packages should be installed via remotes::install_github()
  or devtools::install_github() using the repository paths listed above.
- Bioconductor packages should be installed via BiocManager::install().
